# Sukhmanjot Aulakh Portfolio

A responsive personal portfolio built with React 19, TypeScript, HeroUI 3,
Tailwind CSS 4, and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Content

Project and skill content is centralized in `src/data/projects.ts`. The main
page structure lives in `src/App.tsx`, with the visual system in
`src/styles.css`.

The downloadable resume is bundled at `public/Sukhmanjot_Aulakh_Resume.pdf`.
